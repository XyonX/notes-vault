# Dynamic Programming

## Fibonacci
- Notes: Calculate the nth Fibonacci number using bottom-up DP with tabulation. Demonstrates fundamental DP concepts like base cases, state transitions, and tabulation.

## Climbing Stairs
- Notes: You are climbing a staircase. It takes n steps to reach the top. You can either climb 1 or 2 steps at time. How many distinct ways can you climb to the top? This follows the Fibonacci sequence.

## Tribonacci
- Notes: Calculate the nth Tribonacci number where each term is the sum of the three preceding terms. Extends Fibonacci concept to three previous terms.

## Minimum Cost Climbing Stairs
- Notes: Find the minimum cost to reach the top of the floor where you can start from either step 0 or step 1. Uses DP to make optimal decisions based on previous states.

## Frog Jump
- Notes: Given a number of stairs and a frog that can jump 1 or 2 steps at a time, with energy costs based on height differences, find the minimum energy required to reach the top stair. This is a variation of the climbing stairs problem with cost optimization.

## Unique Paths in Grid
- Notes: Count unique paths from (0,0) to (n-1,n-1) in an n x n grid moving only right or down. Demonstrates 2D DP with multiple approaches: recursive, memoized, tabulation, and space-optimized.
