# longest_unique_subarray\n\n## Solution\nSliding window with map to track last index of each element. Expand r, if duplicate and last index >= l, move l to last+1. Update max length.\n\n## Notes\n- Time: O(n), Space: O(n) worst-case for map.\n- Handles uniques (n), all same (1), empty (0), negatives, zeros, mixed duplicates.\n- Tests: 17 cases including all unique (5), all same (1), duplicates in middle/end/beginning, large/negative/mixed - all pass via asserts.\n- Array version of LeetCode 3 (string chars).\n\n## LeetCode Link\n[Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/) (Medium) - Similar technique.\n\nStatus: solved
