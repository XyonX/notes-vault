# Max Average Subarray I\n\n## Solution\nUses sliding window to maintain running sum of subarrays of fixed size k, computing average at each step and tracking the maximum.\n\n**Time Complexity:** O(n) - single pass over array.\n**Space Complexity:** O(1) - constant extra space.\n\n**LeetCode Link:** [643. Maximum Average Subarray I](https://leetcode.com/problems/maximum-average-subarray-i/)\n\n## Key Concepts\n- Sliding window for fixed-size subarrays.\n- Avoid recomputing sums by subtracting left and adding right elements.\n\nNo known issues; code handles edge cases like k=1 or full array.
