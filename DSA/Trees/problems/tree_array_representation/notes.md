# Tree Array Representation and Preorder Traversal\n\n## LeetCode Link\nNo specific LeetCode problem; this is a fundamental concept for understanding tree representations and traversals.\n\n## Approach\nThis code demonstrates:\n1. **Array Representation of a Binary Tree**: Trees can be represented in arrays using level-order traversal. Parent-child relationships are calculated using indices.\n2. **Iterative Preorder Traversal using Stack**: Simulates recursion by pushing right then left child (to process left first due to stack LIFO).\n\n### Key Formulas\n- Left child of node i: `2*i + 1`\n- Right child of node i: `2*i + 2`\n- Parent of node i: `(i - 1) / 2`\n\n## Time Complexity\n- Index calculations: O(1)\n- Preorder traversal: O(n)\n\n## Space Complexity\n- Stack for traversal: O(h) worst case O(n) for skewed tree\n\n## Key Learnings\n- Array representation saves space compared to pointer-based trees.\n- Iterative traversals avoid recursion stack overflow for deep trees.\n- Note: The preorder code pushes right before left to ensure left is processed first (stack pops last pushed first).\n\n## Practice Count\n1 (Practiced on 2025-09-12)\n\n## Status\nsolved
