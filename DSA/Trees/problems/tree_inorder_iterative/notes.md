# Tree Inorder Iterative Traversal\n\n## LeetCode Link\nNo specific LeetCode problem; fundamental traversal technique.\n\n## Approach\nIterative inorder traversal using a stack. The key innovation is modifying the tree temporarily by nullifying the left child pointer after visiting it. This avoids needing a separate visited flag or two stacks.\n\n- Push root to stack.\n- While stack not empty:\n  - If current has no left: print and pop, then push right if exists.\n  - Else: push left child and nullify current's left pointer.\n\nThis simulates the recursive inorder: left -> root -> right, without recursion.\n\n## Time Complexity\nO(n) - Visits each node once.\n\n## Space Complexity\nO(h) - Stack depth equals tree height (worst O(n) for skewed).\n\n## Key Learnings\n- Modifying tree structure temporarily (nullifying pointers) can simplify iterative traversals, but be cautious as it alters the original tree.\n- This approach avoids recursion stack overflow for deep trees.\n- Alternative: Use Morris traversal for O(1) space, but more complex.\n\n## Practice Count\n1 (Practiced on 2025-09-12)\n\n## Status\nsolved
