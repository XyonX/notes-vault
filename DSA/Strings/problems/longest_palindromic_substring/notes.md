# Longest Palindromic Substring\n\n## LeetCode Link\n[LeetCode #5: Longest Palindromic Substring](https://leetcode.com/problems/longest-palindromic-substring/)\n\n## Approach\nThis solution uses the **Expand Around Center** technique to find the longest palindromic substring. For each character in the string, we expand around it to find palindromes of odd and even lengths.\n\n- **Odd Length Palindromes**: Expand around the current character as center.\n- **Even Length Palindromes**: Expand around the space between current and next character.\n\nWe track the maximum length palindrome found and return the corresponding substring.\n\n## Time Complexity\nO(n²) - Each expansion can take up to O(n) time, done for n centers.\n\n## Space Complexity\nO(1) - Only using constant extra space.\n\n## Key Learnings\n- Efficient way to handle both odd and even length palindromes in one pass.\n- Boundary checking is crucial to avoid index out of bounds.\n\n## Practice Count\n1 (Practiced on 2025-09-12)\n\n## Status\nsolved
