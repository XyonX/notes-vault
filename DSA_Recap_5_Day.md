#### Day 2: Linked Lists, Stacks, and Queues
- **Linked Lists Recap**: Nodes with data and next pointer; singly/doubly. Operations: insertion/deletion (O(1) with pointer), reversal, cycle detection (Floyd's algorithm).
- **Stacks Recap**: LIFO; use for parentheses matching, undo operations. Implement with arrays/lists.
- **Queues Recap**: FIFO; use for BFS, level-order traversal. Implement with deques for efficiency.

#### Day 3: Trees, Binary Search Trees (BST), and Searching/Sorting
- **Trees Recap**: Hierarchical nodes; binary trees have <=2 children. Traversals: inorder, preorder, postorder (recursive/iterative).
- **BST Recap**: Left < root < right; operations like search/insert (O(log n)). Validate, find min/max, LCA.
- **Searching/Sorting Recap**: Binary search on sorted arrays (O(log n)); common sorts: quicksort (O(n log n)), merge sort. Rotated array searches.

#### Day 5: Dynamic Programming, Greedy, and Backtracking
- **DP Recap**: Break problems into subproblems; memoization/tabulation to avoid recomputation. 1D/2D arrays for states.
- **Greedy Recap**: Make locally optimal choices; works for intervals, jumps. Prove optimality.
- **Backtracking Recap**: Explore all possibilities with recursion; prune invalid paths. Used for combinations, subsets.
