

**Interpreted Languages**
this languages are executed line by line by an interpreter at runtime , they dont produce separate machine code file beforehand

execution model- source -interpreter-execution

pros- easy debugging , platform independent
cons- slower compared to compiled language

example-
python java script rubs php perl bash lua

**compiled language**
these are converted  directly into machine code by the compler and directly runs on hardware

executon model- source code -> compiler -> machine code -> execution

pros - fast exection optimzed performancce
cose - less flexible , platform dependent

example - c , cpp , rust , go , swift , fortran , pascall
