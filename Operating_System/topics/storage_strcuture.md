# Computer Storage Hierarchy

Storage in a computer system is organized as a **hierarchy (pyramid)**.

- As we go **up** the pyramid:
    
    - **Speed increases**
        
    - **Capacity decreases**
        
    - **Cost per bit increases**
        
- As we go **down** the pyramid:
    
    - **Speed decreases**
        
    - **Capacity increases**
        
    - **Cost per bit decreases**
        

---

## Storage Pyramid

```
        REGISTER       (fastest, smallest, most expensive per bit)
        CACHE
        MAIN MEMORY
        ELECTRONIC DISK (SSD, Flash)
        MAGNETIC DISK  (HDD)
        OPTICAL DISK   (CD/DVD/Blu-ray)
        MAGNETIC TAPE  (slowest, largest capacity, cheapest per bit)
```

---

## Key Characteristics

### 1. **Register**

- Located inside the CPU.
    
- Holds instructions, addresses, and immediate data.
    
- Very limited in size (few KBs).
    
- Fastest access.
    

### 2. **Cache**

- Small, high-speed memory close to the CPU.
    
- Stores frequently used instructions/data.
    
- Levels: L1 (fastest, smallest), L2, L3 (larger, slower).
    

### 3. **Main Memory (RAM)**

- Volatile (data lost when power is off).
    
- Used for currently running programs and data.
    
- Size: GBs.
    

### 4. **Electronic Disk (SSD/Flash)**

- Non-volatile.
    
- Faster than magnetic disks but more expensive.
    
- No moving parts.
    

### 5. **Magnetic Disk (HDD)**

- Traditional storage, uses spinning platters.
    
- Slower than SSDs but much cheaper per GB.
    
- Large capacities (TBs).
    

### 6. **Optical Disk (CD/DVD/Blu-ray)**

- Uses lasers to read/write.
    
- Slower, mostly used for distribution/media storage.
    

### 7. **Magnetic Tape**

- Sequential access storage.
    
- Very cheap per GB, used for backups/archiving.
    
- Extremely high capacity but very slow.
    

---

✅ Summary: The **storage hierarchy pyramid** balances **speed, cost, and capacity** — from fast but tiny registers at the top to massive but slow magnetic tapes at the bottom.
