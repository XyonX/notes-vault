## 🧠 Summary

System calls are grouped into five categories based on their functionality: **Process Control**, **File Manipulation**, **Device Management**, **Information Maintenance**, and **Communication**. Each category supports specific operations that allow the OS to interact with hardware and software resources efficiently.
